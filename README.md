# pages  

  A modern website that used [Astro][astro], [UnoCSS][unocss] and [daisyUI][daisyui]!  

[cloning-a-repository]: https://docs.github.com/ja/repositories/creating-and-managing-repositories/cloning-a-repository

## Getting Started  

### 1. Clones this repository  

  Please see official guide: [Cloning a repository - GitHub][cloning-a-repository]  

[debugging]: https://code.visualstudio.com/docs/debugtest/debugging

### 2. Installs dependencies  

  ```nu-script
  bun i
  ```  

  Executes a bun installition command.  
  Or, you can use `launch.json`.  

  Please see how to use: [Debug code with Visual Studio Code][debugging]

### 3. Executes development server  

  ```nu-script
  bun run dev
  ```  

### 4. Builds and static preview  

  ```nu-script
  bun run build
  ```  

  Executes a build and output to `dist/`.

  ```nu-script
  bun run prev
  ```
