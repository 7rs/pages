## なんで？  

  今更書き残すほどの事ではないよね。  
  でも、調べてみると今まで知らなかったことも出てくる。そんな備忘録である  

## 見出し／ヘッダー  

  <TabList align="left">
    <Tab tabGroup="header" tabName="コード" icon="material-symbols:code" checked>
      ```mdx

      ### Header #x3  
      #### Header #x4

      ###### Header #x6  
      ```
    </Tab>
    <Tab tabGroup="header" tabName="プレビュー" icon="material-symbols:preview">

        ### Header x3

        ###### Header x6  
      </Window> 
    </Tab>

  たぶん、6段階まで。HTML要素のh1 - h6要素に変換されるから  
  h1(#x1)は１ページに１つというのが通例になっている。また、h1(#x1)と(#x2)は下線が引かれる場合が多い  

  <Blockquote  url="https://developer.mozilla.org/ja/docs/Web/HTML/Reference/Elements/Heading_Elements">
    1つのページに複数の`<h1>`要素を使用することは HTML 標準では認められていますが（入れ子でない限り）、これはよい習慣とはみなされません。
    1 つのページには、ページの内容を説明する1つの`<h1>`要素（文書の`<title>`要素と同様）を置くのが一般的です。  
  </Blockquote>

## リンク  

  <TabList align="left">
    <Tab tabGroup="link" tabName="コード" icon="material-symbols:code" checked>
      ```mdx
      [7rs-dev]: https://7rs.dev/

      - [7rs.dev](https://7rs.dev/)
      - [7rs.dev][7rs-dev]
      ```
    </Tab>
    <Tab tabGroup="link" tabName="プレビュー" icon="material-symbols:preview">
      <Window>
        [7rs-dev]: https://7rs.dev/

        - [7rs.dev](https://7rs.dev/)
        - [7rs.dev][7rs-dev]
      </Window> 
    </Tab>
  </TabList>

  `[]`の中に表示するテキスト、`()`の中にURL。
  で、並べる。`[Example](https://example.com)`  

  まあ、これだと  

  ```mdx
  [Too long](https://www.google.com/search?q=markdown+link&rlz=1C1GCEA_enJP1093JP1093&oq=markdown+link&gs_lcrp=EgZjaHJvbWUyBggAEEUYOdIBCTQ4ODVqMGoxNagCArACAQ&sourceid=chrome&ie=UTF-8)
  ```
  こうなる。
  なので、`[<name>]: <url>`のようにしてリンクを定義しておける。
  使うときは表示するテキストとリンク名を並べる。`[<text>][<link>]`

  ```mdx
  [too-long]: https://www.google.com/search?q=markdown+link&rlz=1C1GCEA_enJP1093JP1093&oq=markdown+link&gs_lcrp=EgZjaHJvbWUyBggAEEUYOdIBCTQ4ODVqMGoxNagCArACAQ&sourceid=chrome&ie=UTF-8

  [Too long][too-long]
  ```

  長いことには変わりないが、本文が汚れるのを防ぐことが出来る
