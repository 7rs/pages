## グラフ  

  MarkdownにもGFMにもGitHubにも、それどころか基本的にはない  
  ただ、Obsidianやフレームワークにプラグインを入れることで使用可能  

  ```mermaid
  pie title Browser
    "Chrome" : 66.19
    "Safari" : 17.25
    "Edge" : 5.2
    "Firefox" : 2.55
    "Samsung Internet" : 2.23
    "Opera" : 2.08
  ```

  Markdown上でテキストベースで[グラフを作成できるMermaid](https://mermaid.js.org/)  
  Obsidianでは標準搭載となっているメジャーなグラフ作成ツール  

  ```d2
  direction: right
  食う -> 寝る -> 遊ぶ
  遊ぶ -> 食う
  ```

  Goで記述されたグラフ作成ツール  
  Markdown用に作られたわけでは無いが、対応させたインテグレーションなどがある
