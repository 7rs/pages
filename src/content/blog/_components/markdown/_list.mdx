## リスト  

  <TabList align="left">
    <Tab tabGroup="list" tabName="コード" icon="material-symbols:code" checked>
      ```mdx
      * アスタリスク
        * アスタリスク入れ子
      * アスタリスク
      + プラス
        + プラス入れ子
      + プラス
      - ハイフン
          - ハイフン入れ子
      - ハイフン
      ```
    </Tab>
    <Tab tabGroup="list" tabName="プレビュー" icon="material-symbols:preview">
      <Window>
        * アスタリスク
          * アスタリスク入れ子
        * アスタリスク
        + プラス
          + プラス入れ子
        + プラス
        - ハイフン
            - ハイフン入れ子
        - ハイフン
      </Window> 
    </Tab>
  </TabList>

  リストは`*`, `+`, `-`を使うことが出来る。
  全て順序なしリスト`<ul>`に変換される  

  <TabList align="left">
    <Tab tabGroup="ordered-list" tabName="コード" icon="material-symbols:code" checked>
      ```mdx
      1. 順序付き
        1. 順序付き入れ子
      2. 順序付き
      ```
    </Tab>
    <Tab tabGroup="ordered-list" tabName="プレビュー" icon="material-symbols:preview">
      <Window>
        1. 順序付き
          1. 順序付き入れ子
        2. 順序付き
      </Window> 
    </Tab>
  </TabList>

  `0-9`までの数字を使うと、順序つきリスト`<ol>`に変換される  
  順番はごっちゃでも変換される  

  <TabList align="left">
    <Tab tabGroup="ordered-list" tabName="コード" icon="material-symbols:code" checked>
      ```mdx
      - [x] 完了済タスク
      - [ ] 未完了タスク
        - [ ] 完了済ネストタスク
        - [x] 未完了ネストタスク
      - [] Not work
      ```
    </Tab>
    <Tab tabGroup="ordered-list" tabName="プレビュー" icon="material-symbols:preview">
      <Window>
        - [x] 完了済タスク
        - [ ] 未完了タスク
          - [ ] 完了済ネストタスク
          - [x] 未完了ネストタスク
        - [] Not work
      </Window> 
    </Tab>
  </TabList>

  GFMでは通常のリストのあとに、`[ ]`か`[x]`を記述することでチェックボックスが表示される。
  これにより、タスクリストを作成できる。`[ ]`のスペースは必須
